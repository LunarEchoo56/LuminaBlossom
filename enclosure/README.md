# Enclosure Manufacturing Files: LuminaBlossom Programmable Light Display

This folder contains the vector graphics files required to cut out LuminaBlossom's circular wooden base. These files are intended for cutting 3mm birch plywood or basswood. They were tested on an XTool D1 Pro 5W laser cutter/engraver. For your convenience, both the original XTool Studio (.xs) as well as color-coded vector graphics (.svg) files are enclosed.

## Files Included

* `luminablossom.svg` - Universal vector format for use with any laser cutter software (LightBurn, Glowforge, etc.).
* `luminablossom.xs` - xTool Studio project file, including settings used for the photographed prototypes.
